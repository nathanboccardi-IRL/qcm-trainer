# QCM Trainer V2

English dark-mode PWA for the ADM-201 150-question bank.

- 65 random questions per attempt
- Immediate correction and source explanation
- 60% passing threshold
- Cloud-synced quiz history with Supabase Auth
- Cloud question-bank replacement by PDF import
- Mac/iPhone responsive PWA

The bundled `questions.json` is derived from the supplied ADM-201 PDF and contains 150 questions.
